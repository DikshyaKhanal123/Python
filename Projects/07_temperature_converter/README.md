# 🌡️ Temperature Converter

A simple Python program that converts temperatures between **Celsius and Fahrenheit**.

## 📌 Features

* Celsius → Fahrenheit
* Fahrenheit → Celsius
* User input
* Menu-based selection
* Invalid choice handling

## 🧠 Concepts Practiced

* Functions
* User Input
* Type Conversion
* Arithmetic Operators
* Conditional Statements
* `if`, `elif`, `else`
* Formatted Strings (f-strings)

## ▶️ How to Run

```bash
py temperature_converter.py
```

## 📐 Formulas

**Celsius to Fahrenheit:**

```text
°F = (°C × 9/5) + 32
```

**Fahrenheit to Celsius:**

```text
°C = (°F - 32) × 5/9
```

## 🎯 Purpose

Built as a beginner Python project to practice **functions, conditions, input, and basic calculations**.
