# 🎲 Dice Roller

A simple **Dice Roller** mini project built using Python. The program randomly generates a number between 1 and 6, just like rolling a real dice.

## 📌 About the Project

This project was created to practice basic Python concepts and the `random` module.

### Features

* Roll a virtual dice
* Generate a random number from 1 to 6
* Roll the dice multiple times
* Option to stop the game

## 🛠️ Technologies Used

* **Python**

## 📚 Concepts Used

* `random` module
* `random.randint()`
* Functions
* `while` loop
* `if-else`
* `input()`
* Variables
* f-strings

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python dice_roller.py
```

Or on Windows:

```bash
py dice_roller.py
```
