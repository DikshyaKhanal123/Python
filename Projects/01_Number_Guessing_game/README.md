# Number Guessing Game 🎯

A simple number guessing game made using Python.

## How it works

* The program has a fixed number.
* The user has to guess the number.
* If the guess is smaller, it shows **Too low**.
* If the guess is bigger, it shows **Too high**.
* When the user guesses the correct number, the game stops.

## Concepts Used

* Variables
* `input()`
* `if-elif-else`
* `while` loop
* `break`
* Comparison operators

## Example

```text
Guess the number: 20
Too low

Guess the number: 40
Too high

Guess the number: 30
Correct number
```

## How to Run

Make sure Python is installed, then run:

```bash
python number_guessing_game.py
```
