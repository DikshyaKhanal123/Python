# 📝 To-Do List

A simple **To-Do List application** built using Python. This project allows users to add, view, and remove tasks through a console-based menu.

## 📌 About the Project

This project was created to practice Python fundamentals and improve problem-solving skills.

### Features

* Add new tasks
* View all tasks
* Remove tasks
* Interactive menu
* Exit the application

## 🛠️ Technologies Used

* **Python**

## 📚 Concepts Used

* Lists
* Functions
* `while` loop
* `for` loop
* `if-elif-else`
* `input()` and `print()`
* `append()`
* `pop()`
* `enumerate()`
* `break`

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python todo_list.py
```

Or on Windows:

```bash
py todo_list.py
```
