
# 🔐 Password Generator

A simple **Password Generator** built using Python. This project generates random passwords based on the length provided by the user.

## 📌 About the Project

This project was created to practice Python fundamentals, functions, loops, and modules.

### Features

* Generate random passwords
* Choose password length
* Include letters, numbers, and special characters
* Display the generated password

## 🛠️ Technologies Used

* **Python**

## 📚 Concepts Used

* Functions
* `for` loop
* `input()`
* `random` module
* `string` module
* `random.choice()`
* String concatenation

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python password_generator.py
```

Or on Windows:

```bash
py password_generator.py
```
